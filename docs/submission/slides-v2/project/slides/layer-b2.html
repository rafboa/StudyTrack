Tugas 2 · Layer B — Backend (2 dari 2): endpoint

GET /api/tasks:

  now = new Date()

  tasks = userTasks.map(add kategori, sisa_menit, mata_kuliah)

  sort by group rank (mendekati=0, overdue=1, normal=2), lalu dalam grup:

     mendekati: sisa_menit asc

     overdue:   sisa_menit desc   (paling baru lewat dulu)

     normal:    created_at desc

  respond { tasks, server_time: now.toISOString() }

Endpoint GET /api/tasks. Urutan grup Mendekati, lalu Overdue, lalu Normal. Di dalam grup: mendekati berdasarkan sisa_menit naik, overdue berdasarkan sisa_menit turun sehingga yang paling baru lewat tampil dulu, normal berdasarkan created_at terbaru dulu. Hanya tugas milik pengguna yang login (F04). Respons juga membawa server_time.
